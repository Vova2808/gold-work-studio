# Спецификация Gold Work Studio

## Продукт

Portable-приложение для Windows, которое проводит пользователя через полный цикл создания видео: идея, сценарий, персонажи и локации, сцены, изображения или анимация, озвучка, субтитры, музыка и сборка MP4.

Пользователь не устанавливает Node.js, Python или FFmpeg. Программа распространяется архивом с готовыми файлами. Внешние сервисы работают по модели BYOK: пользователь вводит собственные ключи в настройках.

## Режимы

- Standard: изображения с панорамированием и масштабированием через FFmpeg.
- Pro: анимация каждой сцены через подключаемый видеопровайдер.

## Надёжность

- Проекты и задания сохраняются локально.
- Каждая сцена обрабатывается отдельной задачей.
- Завершённые результаты кэшируются и не генерируются повторно.
- Сетевые ошибки и ответы 429/5xx повторяются до трёх раз.
- Приложение продолжает незавершённую работу после перезапуска.
- Ошибки внешних API показываются понятным языком и не завершают приложение.
- API-ключи не записываются в репозиторий или обычные текстовые файлы.

## Провайдеры

Архитектура не зависит от конкретной нейросети. Отдельные адаптеры реализуют сценарии, изображения, видео, озвучку и транскрибацию. До подключения реальных API используется локальный mock-режим.

## Основные сущности

Проект, пресет, персонаж, локация, сцена, задача, медиафайл, настройки провайдера и запись расходов.

## Текущий этап

Рабочая основа реализована: Electron, React, TypeScript, локальные проекты, редактор сцен, настройки, предпросмотр, таймлайн и сохраняемая mock-очередь. Следующий этап — отдельные инструменты превью, аватаров и SEO, затем подключение реальных провайдеров через существующие адаптеры.
