# Gold Work Studio: итог работы текущего чата и промпт для ревью

Обновлено: 2026-08-31

> Архивный срез. Не использовать как текущий план: после этого файла были реализованы автоматический Stock, исправления сценария/озвучки, VisualBeat и Remotion-render. Актуальные документы — `ROADMAP.md` и `NEXT_CHAT_HANDOFF_2026-09-05.md`.

Этот файл нужен, чтобы новый чат быстро понял решения владельца, уже внесённые изменения, текущее состояние программы и границы следующего ревью. Главный roadmap проекта находится в `ROADMAP.md`.

## 1. Итоговая цель продукта

Gold Work Studio должен стать локальной Windows-программой для создания длинных YouTube-роликов в стиле VidRush:

1. Пользователь выбирает профиль YouTube-канала.
2. Master Prompt канала автоматически участвует во всех текстовых задачах этого канала.
3. Для отдельного ролика пользователь задаёт тему/промпт и при необходимости добавляет TXT-транскрипции конкурентов.
4. AnyModel пишет текст, сценарий, главы и промпты для сцен.
5. Lumean создаёт озвучку.
6. Stock-сервисы и Google Flow дают изображения и видео.
7. Редактор и в будущем Remotion собирают материалы, звук, музыку и motion-графику.
8. Результат первой версии - готовый MP4 без автоматической публикации на YouTube.

Программа остаётся локальной, рассчитанной примерно на двух пользователей. Сервер, облачная команда и сложная многопользовательская архитектура не нужны.

## 2. Зафиксированные решения владельца

- Главный ориентир по логике продукта и качеству - VidRush.
- Первый обязательный формат - длинные YouTube-ролики: 10, 20, 30, 40, 50, 60 минут и при необходимости больше часа.
- Master Prompt создаётся отдельно для каждого канала.
- При создании профиля канала отдельные поля `ниша` и `аудитория` не нужны. Они описываются внутри Master Prompt.
- Внешний гайд VidRush используется для подготовки Master Prompt: `https://dev.docs.vidrush.ai/docs/in-depth-prompting`.
- Пользователь может подготовить Master Prompt во внешнем Claude, ChatGPT или DeepSeek и вставить готовый текст в программу.
- AnyModel используется только для текста: чат, сценарий, главы, заголовки, планы, правки и промпты.
- Модель AnyModel выбирается в самом AI-чате и сохраняется для темы чата.
- Google AI Studio не является основным способом генерации и не должен иметь отдельную пользовательскую вкладку настроек.
- Основной генератор AI-изображений и AI-видео - Google Flow через подключённые аккаунты.
- Единственный основной TTS - Lumean. AnyModel не используется как основной TTS.
- Голоса добавляются пользователем на сайте Lumean. В Gold Work Studio выбираются уже сохранённые голоса после нажатия `Обновить список`.
- По умолчанию используются stock-фото и stock-видео. Для проекта доступны `Stock`, `AI` и `Mix`.
- `Mix` означает сочетание stock и AI в одном ролике.
- Визуальный стиль описывается в Master Prompt, а не дублируется отдельными обязательными полями профиля.
- Motion-шаблон можно выбирать отдельно.
- Субтитры не должны создаваться, настраиваться или рендериться в Gold Work Studio. Владелец добавит их в CapCut либо выпустит ролик без субтитров.
- TXT-транскрипции конкурентов принадлежат только конкретному ролику и не изменяют постоянный профиль канала.
- VeoNonStop рассматривается как дополнительный API-провайдер, но не блокирует первую версию. Документация: `https://veononstop.org/api-docs.html`.
- Remotion планируется использовать как движок композиции, предпросмотра и рендера под собственным интерфейсом Gold Work Studio. Пользователь не должен писать код Remotion.
- Существующую возможность точечно перегенерировать изображение, видео или озвучку сцены необходимо сохранить при будущем подключении Remotion.

## 3. Анализ продукта и roadmap

В начале работы был разобран текущий софт, пользовательский путь и список интеграций. Старый перегруженный план был заменён рабочим roadmap, в котором:

- описана конечная цель продукта;
- зафиксированы решения владельца;
- разделены постоянный Channel Profile и задание конкретного ролика Video Brief;
- этапы расставлены по приоритетам `P0/P1/P2`;
- первым этапом поставлены понятные настройки;
- вторым этапом поставлены профили каналов, Master Prompt и long-form сценарий;
- далее идут Lumean, stock, Flow, Remotion, конвейер одной кнопкой и проверка качества;
- отдельно записано окончательное решение не добавлять субтитры.

Текущий статус roadmap: этап понятных настроек принят владельцем; этап профилей каналов и сценария находится в работе. Базовые профили и Video Brief уже реализованы, полноценная генерация long-form сценария по главам ещё не реализована.

## 4. Переработка настроек

Раздел настроек был переработан в более понятную структуру по сервисам.

Сделано:

- добавлен компактный обзор состояния сервисов;
- AnyModel, Lumean, Google Flow, Stock, YouTube и хранение разделены по смыслу;
- убрана пользовательская вкладка `Дополнительно`;
- убрана отдельная настройка Google AI Studio из основного пользовательского пути;
- в пользовательских настройках AnyModel оставлено подключение API-ключа;
- выбор текстовой модели перенесён в AI-чат;
- результат проверки сервиса показывается рядом с тем сервисом или Flow-аккаунтом, который проверяется;
- ошибки и успешные состояния стали заметнее и понятнее;
- технические поля Flow, cookies и proxy сгруппированы логичнее;
- Lumean вынесен в отдельный понятный раздел озвучки.

Важно: внутренняя модель транскрибации может продолжать использоваться как технический fallback, если у YouTube-ролика нет доступных captions. Пользователь больше не обязан выбирать или понимать эту модель в настройках.

## 5. Исправления Google Flow и proxy

В этом чате владелец столкнулся с несколькими проблемами входа Google Flow:

- Google сообщал, что в браузере отключён или не поддерживается JavaScript;
- после входа открывалась страница Google One вместо Flow;
- SOCKS5 proxy с авторизацией давал `ERR_SOCKS_CONNECTION_FAILED`;
- с тем же proxy вход работал в Dolphin, но не в Gold Work Studio;
- иногда окно входа оставалось белым или Flow не возвращался после Google-редиректа.

Внесённые исправления:

- для окна входа явно включена поддержка JavaScript;
- Electron-маркер удалён из User-Agent, используется совместимый Chrome User-Agent;
- добавлена логика возврата из Google One обратно на страницу Flow;
- безопасные Google navigation abort не считаются фатальной ошибкой входа;
- добавлена корректная обработка SOCKS5 proxy с логином и паролем через локальный browser proxy bridge;
- proxy применяется к Flow-сессии, а не только хранится в настройках;
- отключён прямой non-proxied WebRTC UDP, чтобы Flow-окно не обходило настроенный proxy этим путём;
- улучшены сообщения о сетевых ошибках, cookies и повторном входе;
- добавлены проверки parsing proxy и browser bridge.

После этих изменений владелец подтвердил, что Flow-аккаунты подключаются и proxy работает. Генерация изображений и видео через Flow ранее также была проверена владельцем на реальном аккаунте.

## 6. Реализованные профили YouTube-каналов

Добавлена полноценная локальная сущность `ChannelProfile`.

Профиль хранит:

- название канала;
- страну;
- код и название языка;
- единый Master Prompt;
- выбранный сохранённый голос Lumean;
- длительность ролика по умолчанию;
- источник материалов `Stock/AI/Mix`;
- выбранный motion-шаблон;
- даты создания и обновления.

Хранение:

- профили сохраняются локально в JSON;
- запись выполняется атомарно;
- битый JSON откладывается как corrupt-файл, чтобы приложение не переставало запускаться;
- существующие старые проекты автоматически переносятся в профиль `Старые проекты`;
- проект и тема чата получили связь `channelProfileId`;
- старые SQLite-таблицы чатов мигрируются добавлением `channel_profile_id`;
- удаление канала блокируется, пока к нему привязаны ролики.

## 7. Новый стартовый экран `Мои каналы`

При каждом новом запуске Gold Work Studio первым открывается экран `Мои каналы`.

На нём реализованы:

- список локальных каналов;
- количество роликов в каждом канале;
- язык и флаг;
- выбранный голос Lumean;
- кнопка `Создать канал`;
- пустое состояние для первого запуска.

Системные emoji-флаги на Windows отображались как буквы `RU/IE`, поэтому вместо зависимости от системного шрифта добавлены локальные SVG-флаги. В мастере доступны 249 стран, поиск по стране или языку и отдельная прокрутка списка. Для этого добавлена зависимость `country-flag-icons`.

## 8. Мастер создания и редактирования канала

Мастер состоит из трёх шагов.

### Шаг 1: название и язык

- название канала вводится вручную;
- страна и основной язык выбираются из прокручиваемого списка;
- отображаются настоящие локальные флаги;
- отдельные поля ниши и аудитории отсутствуют.

### Шаг 2: Master Prompt

- большое поле для вставки готового Master Prompt;
- счётчик символов;
- кнопка открытия гайда VidRush;
- сохранение невозможно при пустом Master Prompt.

### Шаг 3: производственные значения

- выбор уже сохранённого голоса Lumean;
- кнопка обновления списка голосов;
- переход в настройки, если Lumean ещё не подключён;
- длительность по умолчанию;
- источник материалов `Stock/AI/Mix`;
- motion-шаблон;
- финальный предпросмотр Master Prompt перед сохранением.

Существующий выбранный голос не пропадает при редактировании профиля, даже если каталог Lumean временно не загрузился.

## 9. Рабочая область выбранного канала

После открытия канала пользователь видит:

- название, язык и флаг;
- выбранный Lumean-голос;
- длительность, источник материалов и motion-шаблон;
- только ролики этого канала;
- только чаты и использованные темы этого канала;
- действия `Изменить профиль`, `Новый ролик` и `Открыть AI Генератор`.

Глобальные старые экраны проектов сохранены для совместимости, но внутри рабочего пространства канала данные фильтруются по `channelProfileId`.

## 10. Новый ролик и материалы конкурентов

Форма `Новый ролик` содержит:

- рабочее название проекта;
- подробную тему/задачу для AnyModel;
- загрузку одной или нескольких TXT-транскрипций конкурентов;
- список добавленных файлов с именем и размером текста;
- удаление ошибочно добавленного файла до создания проекта.

Защита TXT:

- принимаются только выбранные пользователем TXT-файлы;
- размер одного файла ограничен 5 МБ;
- BOM удаляется;
- в проект сохраняются имя и текст, но не требуется повторное чтение исходного файла.

Video Brief сохраняется внутри проекта и содержит prompt ролика и массив транскрипций. Эти данные не записываются в постоянный профиль канала.

## 11. Передача контекста в AnyModel

При написании сценария сервер собирает постоянный контекст в следующем порядке:

1. Master Prompt выбранного канала.
2. Prompt/задача конкретного ролика.
3. TXT-транскрипции конкурентов с указанием имени файла.
4. Сохранённый анализ или полный диалог AI Генератора.

Дополнительно:

- анализ ссылок YouTube получает Master Prompt выбранного канала;
- память прошлых проектов фильтруется по выбранному каналу;
- темы чата создаются с `channelProfileId`;
- AI Генератор показывает только темы выбранного канала;
- новый ролик сразу создаёт связанную тему чата;
- при открытии AI Генератора связанный prompt ролика загружается в чат;
- кнопка сборки сценария использует уже созданный проект ролика и не создаёт второй дубликат.

Проект наследует из профиля язык, длительность, Lumean-голос и режим AI-видео. Эти defaults применяются и к обычному созданию проекта, и к проектам, созданным из анализа референса.

## 12. Решение по субтитрам

Из пользовательского интерфейса убраны:

- пункт навигации `Субтитры`;
- быстрый инструмент субтитров на Dashboard;
- блок субтитров в настройках проекта;
- переключатели субтитров в списке проектов;
- дорожка субтитров в основном таймлайне и preview.

При нормализации старых проектов `settings.subtitles.enabled` принудительно становится `false`.

В кодовой базе пока могут оставаться старые внутренние типы, renderer-функции и FFmpeg/ASS helpers для совместимости со старыми данными и тестами. Они не доступны пользователю и не должны снова подключаться к интерфейсу или рендеру. Отдельное физическое удаление legacy-кода можно сделать позже после проверки, что оно не затрагивает старые проекты.

## 13. Обсуждённая архитектура Lumean

Полная новая схема Lumean ещё не реализована, но зафиксирован правильный подход:

- нельзя озвучивать независимые куски по 5 секунд: это создаёт вдохи, охи и другие артефакты;
- сценарий должен озвучиваться длинными главами или крупными смысловыми блоками;
- после генерации измеряется реальная длительность аудио;
- текст главы синхронизируется с аудио по предложениям/словам или timestamps провайдера;
- пятисекундные визуальные фрагменты раскладываются поверх уже готовой длинной озвучки;
- visual prompt каждой сцены должен соответствовать именно речи на этом временном участке;
- перегенерация одной главы должна заменять её аудио и пересчитывать только зависимый диапазон таймлайна.

Это следующий крупный этап после завершения long-form сценария.

## 14. Обсуждённая архитектура Remotion и редактора

Принято архитектурное направление:

- Remotion можно использовать как нижний движок композиции и рендера;
- собственный интерфейс Gold Work Studio остаётся главным редактором;
- Remotion Player встраивается в интерфейс как preview;
- текущие материалы проекта передаются в Remotion через typed input props;
- справа остаётся панель свойств и перегенерации выбранной сцены;
- таймлайн показывает изображения, видео, озвучку, музыку, текст и motion-шаблоны;
- после замены изображения/видео обновляется asset сцены, а не пересоздаётся весь проект;
- экспорт или открытие в Remotion Studio может быть дополнительным продвинутым режимом.

Remotion в кодовую базу на этом этапе ещё не добавлен. Существующий редактор продолжает использоваться.

## 15. Что изменено в проверках

Добавлены или обновлены проверки:

- локальное сохранение ChannelProfile;
- сохранение `channelProfileId` в SQLite-чате;
- фильтрация тем по каналу;
- SOCKS5 browser proxy bridge;
- Flow User-Agent и возврат после Google One;
- обновлён UI smoke под стартовый экран каналов;
- UI smoke создаёт канал и проверяет открытие рабочей области;
- UI smoke подтверждает отсутствие пользовательской студии субтитров.

На момент записи файла проходят:

- `pnpm typecheck`;
- `pnpm build`;
- `pnpm test`: 19 core-тестов и 54 desktop-теста, всего 73;
- `pnpm --filter @gold-work/desktop exec electron scripts/ui-smoke.mjs`.

При production build остаётся предупреждение Vite о крупном JS chunk. Сборка завершается успешно, но в будущем `App.tsx`, редактор и каталог флагов стоит разделить на lazy chunks.

## 17. Что ещё не сделано

Следующие части не следует ошибочно считать готовыми:

1. Полноценный typed prompt builder с предпросмотром всего итогового запроса перед каждым AI-вызовом.
2. Long-form сценарий по главам: brief, план, подтверждение, генерация глав, проверка повторов и финальное утверждение.
3. Реальная новая схема озвучки Lumean по главам и пересчёт таймлайна по длительности аудио.
4. Pexels и Pixabay для автоматического stock-поиска.
5. Автоматический выбор `Stock/AI/Mix` для каждой сцены.
6. VeoNonStop API client и очередь.
7. Remotion Player, Remotion renderer и библиотека motion-шаблонов.
8. Полный путь одной кнопкой от нового профиля канала до финального длинного MP4.
9. Проверка нового выбора Lumean-голоса на реальном API в мастере канала.
