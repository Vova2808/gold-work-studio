## Ограничения и следующий шаг

Канал контрольного проекта отсутствует в просмотренных при переносе профилях; произвольная привязка не создана, открывать из общего списка. Final.mp4 по существующему контракту создаётся в workspace\projects\<id>; Whisper/CLIP остаются в LOCALAPPDATA на C:. Stop без ID может ждать ответа/таймаута уже отправленной операции; удаление проекта не является единой транзакцией на случай убийства процесса между файлами. Сбой установщика после выхода Electron статически не исключён. Эти границы сохранены в независимых отчётах.

После новой редакции выполнялись только чтение/статический разбор, файловые операции и Git. Никаких тестов/check/lint/typecheck/сборок/программы/провайдеров/рендера. Новых тестов нет. Hooks не обнаружены; workflow release-updates.yml запускается только на v*-тегах или вручную. Remote main при чтении — ffd6209.

Данные JSON сформированы из неизменённых оригиналов с DateKind String; изменялись только пути по карте. По выборочному независимому чтению даты, 63 сцены, failed/materials и пустая очередь сохранены; полное сравнение всех полей не заявляется.
