# Gold Work Studio

Portable Windows-приложение для создания роликов: от идеи и сценария до сцен, озвучки, субтитров и финального MP4.

Сейчас проект находится на этапе рабочей основы. Внешние нейросети заменены mock-провайдерами, поэтому разработка и проверка интерфейса не требуют API-ключей.

## Что уже работает

- создание, изменение, дублирование и удаление проектов;
- локальное сохранение проектов между запусками;
- редактор сцен с изменением порядка, текста озвучки и промптов;
- сохранение настроек озвучки, изображений, видео, музыки и сборки;
- студия субтитров с живым предпросмотром;
- предпросмотр сцен и таймлайн проекта;
- mock-конвейер `озвучка + изображения + видео → Final.mp4`;
- очередь до четырёх параллельных задач, пауза, продолжение, остановка и повтор;
- восстановление незавершённых задач после перезапуска приложения.

Mock-режим не обращается к платным сервисам и не создаёт настоящие медиафайлы. Он проверяет весь путь данных и готовит точки подключения будущих API-адаптеров.

## Разработка

Требования: Node.js 20+ и pnpm.

```powershell
pnpm install
pnpm dev
```

Проверки:

```powershell
pnpm typecheck
pnpm test
pnpm build
```

Если команда `pnpm` не найдена, один раз выполните:

```powershell
npm install -g pnpm
```

Portable-сборка без установщика:

```powershell
pnpm portable
```

Результат появится в `release/`. Пользователь распаковывает архив и запускает приложение без установки Node.js или FFmpeg.

## Локальные данные

В режиме разработки Electron сохраняет `projects.json` и `queue.json` в своей пользовательской папке данных. Portable-версия будет хранить их в каталоге `workspace` рядом с программой. Эти файлы не отправляются в GitHub.

Политика mock-очереди: четыре параллельные задачи, максимум три попытки и интервалы автоматического повтора 1 и 3 секунды.

## Безопасность

Никогда не добавляйте в Git `.env`, API-ключи, токены, пользовательские проекты и сгенерированные медиа. Настоящие ключи будут сохраняться локально через Electron `safeStorage`.
