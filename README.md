# Gold Work Studio

Локальное Windows-приложение для создания роликов: от проекта и сценария до изображений, озвучки, очереди задач и финального MP4.

Проект находится на этапе рабочей основы. Платные нейросети пока заменены безопасными mock-адаптерами, поэтому разработка и проверка интерфейса не расходуют API-кредиты. При этом Standard-сборка уже создаёт настоящие локальные файлы и `Final.mp4` через встроенный FFmpeg.

## Что уже работает

- создание, изменение, дублирование и удаление проектов;
- редактор сцен, промптов, озвучки и длительности;
- настройки изображений, видео, музыки, субтитров и сборки;
- локальная очередь до четырёх параллельных задач;
- пауза, продолжение, остановка и автоматические повторы;
- восстановление незавершённой очереди после перезапуска;
- отдельная папка каждого проекта и каждой сцены;
- сохранение `project.json`, `scenario.json`, промптов и текста озвучки;
- локальные изображения-заглушки и WAV-файлы для проверки всего конвейера;
- Standard-режим: изображения, эффект Ken Burns, плавные затемнения и настоящий `Final.mp4`;
- точечная перегенерация выбранной сцены без запуска всего проекта;
- открытие папки проекта из окна предпросмотра;
- единый TXT-журнал запуска, действий очереди, IPC-команд и ошибок;
- интерфейсы адаптеров для Gemini/Claude, Nano Banana, ElevenLabs и Veo.
- чатовый разбор ссылки на референс: ниша, аудитория, хук, структура, улучшения и создание проекта со сценами;

Внешние модели пока не вызываются. Для них подготовлены переключаемые адаптеры, которые будут подключены после получения легальных API-ключей или официального способа авторизации.

AnyModel уже подключён как опциональный реальный провайдер: OpenAI-совместимый чат для сценария и анализа, `/v1/images/generations` для изображений и асинхронный `/v1/videos/generations` для видео. Без сохранённого ключа приложение автоматически остаётся в безопасном mock-режиме.

## Разбор ролика через AI-чат

В AI-генератор можно вставить ссылку на YouTube, Rutube или другой доступный ролик и добавить пожелание. Чат формирует разбор ниши, аудитории, хука, структуры и удержания, после чего предлагает самостоятельный улучшенный сценарий. Следующими сообщениями можно уточнять результат, например: «сделай хук жёстче», «сократи до Shorts» или «добавь больше интриги». Кнопка «Создать проект и сценарий» переносит результат в редактор сцен, откуда запускаются изображения, озвучка, видео и финальная сборка.

Сейчас используется демонстрационный анализатор, который проверяет весь путь без расходов. После подключения провайдера адаптер будет получать разрешённые метаданные и транскрипт ролика и передавать их в Gemini или Claude. Система анализирует приёмы и структуру, но не должна дословно копировать чужой сценарий, персонажей или брендинг.

## Запуск

Требования: Node.js 20+ и pnpm.

```powershell
cd "C:\Users\rosup\OneDrive\Документы\Софт Gold Work Sudio"
pnpm install
pnpm dev
```

Если команда `pnpm` не найдена:

```powershell
npm install -g pnpm
```

Проверки:

```powershell
pnpm typecheck
pnpm test
pnpm build
```

## Папки проектов

В режиме разработки данные Electron находятся в пользовательской папке приложения. Исходники проектов сохраняются внутри:

```text
workspace/
  projects/
    <project-id>/
      project.json
      scenario.json
      Final.mp4
      scenes/
        001-<scene-id>/
          image.bmp
          image-prompt.txt
          voice.wav
          narration.txt
          scene.json
          scene.mp4
```

Точный путь показывается в разделе «Настройки». Открыть нужную папку можно из предпросмотра проекта.

## Лог программы

Журнал хранится в `logs/gold-work-studio-log.txt` внутри папки данных приложения. Точный путь и кнопка открытия находятся в разделе «Настройки».

В лог попадают запуск и закрытие программы, действия с проектами, состояние очереди, выполнение и повтор задач, ошибки FFmpeg, ошибки Electron и интерфейса. API-ключи, токены, пароли и секреты автоматически заменяются на `[REDACTED]`. При размере 5 МБ текущий файл переносится в `gold-work-studio-log-previous.txt`.

## Очередь

- параллельных задач: 4;
- максимум попыток: 3;
- интервалы автоматического повтора: 1 и 3 секунды;
- готовые сцены сохраняются сразу;
- перегенерация одной сцены сохраняет остальные результаты.

## Переносимая версия

Позже приложение будет распространяться архивом без установщика. Команда сборки:

```powershell
pnpm portable
```

Результат появляется в `release/`. В переносимую версию войдёт FFmpeg, поэтому пользователю не потребуется отдельно устанавливать Node.js или FFmpeg.

## Безопасность

Не добавляйте в Git `.env`, API-ключи, токены, пользовательские проекты и сгенерированные медиа. Будущие секреты должны храниться локально через Electron `safeStorage`.

Ключ AnyModel вводится только в разделе «Настройки → AI и сценарии». Electron шифрует его через Windows `safeStorage`; интерфейс получает только статус «ключ сохранён», но никогда не получает сам ключ. Если ключ был опубликован в сообщении, скриншоте или репозитории, его необходимо отозвать и создать новый.
