# Gold Work Studio

Локальная Windows-студия для работы с видео: готовый сценарий → сцены и озвучка → подбор или генерация материалов → монтаж → редактируемый таймлайн → экспорт MP4.

Версия пакета: **0.2.6**. Снимок рабочих исходников от **9 ноября 2026 года**, исходный коммит разработки `eb8716601cdcd7ef0e55b5a41d949b7bce185cab`.

## Возможности

- **Stock Documentary:** поиск фото и видео, проверка материалов, озвучка, подготовка монтажа и редактирование перед экспортом.
- **AI Story:** генерация материалов, работа с персонажами и сохранение существующих проектов.
- Каналы, проекты, сценарии, очередь, контрольные точки и продолжение незавершённых операций.
- Многодорожечный редактор: видео, голос, текст, шаблоны, переходы, эффекты, звуки и музыка.
- Локальное хранение проектов; ключи и аккаунты внешних сервисов подключаются в настройках приложения.

Приложение находится в активной доработке. Полный подбор материалов и экспорт длинного фильма после последних изменений ещё требуют проверки. Сборка и локальные тесты не подтверждают работу всех внешних провайдеров.

## Запуск

Рабочая среда: Windows, Node.js **24.19.0**, pnpm **11.9.0**. Версия pnpm закреплена в `package.json`.

```powershell
pnpm install --frozen-lockfile
pnpm build
.\START-GoldWork.cmd
```

Для разработки после первой сборки:

```powershell
pnpm dev
```

`START-GoldWork.cmd` запускает собранное приложение. `pnpm dev` запускает режим разработки. Выберите один способ запуска. Сборка подготавливает библиотеки workspace, Electron main/preload и интерфейс.

## Проверки и сборки

```powershell
pnpm typecheck
pnpm portable
pnpm installer
```

Быстрая проверка после первоначальной сборки: `powershell -NoProfile -File scripts/verify-local.ps1`. Полный локальный набор по отдельному запросу: `powershell -NoProfile -File scripts/verify-local.ps1 -Full`.

Установщик и portable-файл появляются в `release/`. Команда `pnpm installer` собирает установщик без публикации. Команды `release:updates`, `check:flow` и проверки обновлений обращаются к внешним сервисам или выполняют установку; используйте их только для соответствующей задачи.

## Структура

| Каталог | Содержимое |
|---|---|
| `apps/desktop/src` | Electron, IPC, провайдеры, очередь, хранилища и FFmpeg |
| `apps/renderer/src` | React-интерфейс и редактор |
| `apps/renderer/public` | Ресурсы интерфейса |
| `packages/shared` | Типы, тайминг и общие настройки |
| `packages/core` | Проекты и доменная логика |
| `packages/remotion-video` | Композиции, motion и предпросмотр |
| `scripts` | Запуск, идентификатор сборки и локальная проверка |
| `apps/desktop/scripts` | Проверки, используемые командами проекта |

В репозиторий входят рабочий код, ресурсы интерфейса, тесты и конфигурация сборки. Локальные проекты, фильмы, ключи, cookies, профили браузера, зависимости, готовые сборки, отчёты и разовые эксперименты не включены. Лицензии географических данных описаны в [packages/shared/GEOGRAPHY_LICENSE.md](packages/shared/GEOGRAPHY_LICENSE.md).
