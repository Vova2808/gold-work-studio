# Gold Work Studio

Локальная студия для Windows: сценарий → сцены и озвучка → подбор или генерация материалов → автоматический монтаж → редактируемый таймлайн → `Final.mp4`. Electron, React, TypeScript, Remotion и FFmpeg. Данные проектов и ключи провайдеров хранятся на компьютере пользователя; собственного облачного сервиса и регистрации нет.

**На 02.10.2026 это функциональная версия в активной доработке, не завершённый продукт.** Реальные интеграции уже работают, приложение не ограничивается mock-адаптерами. Главная незакрытая задача — быстро и стабильно получать подходящие материалы. Цель «18-минутный фильм за 2–3 часа от сценария до Final» пока не подтверждена.

Датированные файлы в корне сохраняют историю. Старые заявления о завершении, PID и тестах не заменяют актуальную проверку. Ссылки на `captures/` в исторических документах ведут к локальным доказательствам, которых нет в GitHub; последние результаты вынесены отдельно по ссылке выше.

## Два режима

| Режим | Назначение и текущая граница |
|---|---|
| **Stock Documentary** | Основной приоритет. Поиск фото/видео, проверка содержания и качества, озвучка, автоматические шаблоны, переходы, эффекты и редактируемый монтаж. Реальные источники и AnyModel. Качество и скорость полного подбора ещё не приняты. |
| **AI Story** | Генеративные истории. Пользовательское направление — Google Flow через подключённый аккаунт и Lumean/LumenApp для озвучки. Существующие проекты сохранять. Последние stock-тесты не подтверждают свежую работоспособность полного Flow-цикла. |

Готовый сценарий сохраняется дословно. Материалы и монтаж должен выбирать сам продукт, без ручного назначения разработчиком. Старые режимы/адаптеры в коде могут оставаться для совместимости; это не означает, что их следует включать в новые проекты.

## Что реализовано в коде

- Проекты, каналы, сценарии, очередь, сохранение промежуточных результатов и продолжение с контрольных точек.
- Поиск, загрузка, ранжирование и проверка реальных кадров; кэширование, группировка запросов, короткие предварительные пробы видео и ограниченные бюджеты попыток.
- Защита неизвестных результатов платных запросов: обрыв после принятия запроса не даёт права автоматически оплатить его повторно.
- Автомонтаж: **98 шаблонов** в каталоге, motion-графика, подписи, переходы, SFX, рамочный CRT и полноэкранный телевизионный эффект с движущимися полосами.
- Многодорожечный редактор: видео, голос, шаблоны, текст, звуки, эффекты, музыка; свойства клипов, перемещение/обрезка, отмена, независимая высота дорожек.
- Музыкальная дорожка с импортом, громкостью и затуханиями. Полностью автоматический подбор и скачивание музыки Pixabay ещё не подтверждены.
- Ограничение тяжёлых фоновых задач, оптимизация сохранения больших проектов, виртуализация таймлайна и уменьшение нагрузки React в обычном dev-запуске.

Наличие функции в коде не доказывает качество на всём фильме, всех темах или любом железе. Полное соответствие редактору и монтажу Vidrush не принято.

## Запуск из исходников

Последняя рабочая среда: Windows, Node.js **24.19.0**, pnpm **11.9.0** (закреплён в `package.json`). Использовать существующий lockfile.

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm dev
```

Сборка подготавливает `dist` библиотек и идентификатор приложения. Перед запуском проверить существующие процессы: не запускать дубликат. Ключи и аккаунты подключаются в настройках; репозиторий их не содержит. Реальное производство может расходовать лимиты внешних сервисов.

После изменений — адресная проверка затронутого пути. Быстрая проверка типов:

```powershell
powershell -NoProfile -File scripts/verify-local.ps1
```

Полный gate — отдельно при необходимости: `scripts/verify-local.ps1 -Full`. Это не проверка качества живых провайдеров. `pnpm portable` собирает переносимую версию, но актуальная portable-приёмка в последнем stock-инкременте не проводилась.

## Устройство репозитория

| Каталог | Ответственность |
|---|---|
| `apps/desktop/src` | Electron main/IPC, интеграции, очередь, хранилище, загрузка, FFmpeg |
| `apps/renderer/src` | React-интерфейс, workflow, редактор, настройки |
| `packages/shared/src` | Сериализуемые типы, тайминг, каталог шаблонов и переходов |
| `packages/core/src` | Доменная логика проектов и очереди; потребители используют `dist` |
| `packages/remotion-video/src` | Изображение фильма, композиции, motion и предпросмотр |
| `apps/desktop/scripts` | Проверки и исторические служебные инструменты; читать перед запуском |
| `docs` | Актуальная передача проекта и публикуемые результаты |

Скрипты `*live*`, миграции, очистка и QA с абсолютными путями могут обращаться к платным сервисам или изменять пользовательские данные. Не запускать каталог целиком. Фильмы, исходные медиа, секреты, логи, `captures/`, зависимости и сборки исключены из Git. GitHub — копия исходников и документации, **не резервная копия фильмов и оплаченных голосов**.
