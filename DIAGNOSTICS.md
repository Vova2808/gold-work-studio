# Запуск и диагностика — 2026-09-11

## Для пользователя

Консоль растягивается мышью за верхнюю границу по всей ширине. Высота сохраняется локально после сворачивания, навигации и перезапуска; при уменьшении окна консоль ограничивается доступным местом. Двойной щелчок по границе возвращает 340 px; с фокусом на границе стрелки ↑/↓ изменяют размер, Home/End выбирают минимум/максимум. Прокручиваются строки лога, а не заголовок и панель поиска. Проверено в `diagnostics-ui-smoke.mjs` реальными событиями мыши/клавиатуры, включая reload и малый размер окна; renderer typecheck и desktop build прошли (2026-09-11).

При запуске виден экран загрузки, затем независимые проверки подключений. «Открыть приложение» и Escape сразу закрывают окно, не отменяя проверки. Результаты возвращаются через «Подключения» внизу боковой панели. «Проверить снова» доступно после завершения текущего прохода. Неподключённые API серые, сетевые ошибки красные; частично доступные Flow-аккаунты отмечаются предупреждением.

Проверяются ключи/доступ к метаданным, сессии Flow, наличие FFmpeg и совпадение версии main/renderer. Никаких completion, TTS-заказов, изображений и Veo-видео. Метаданные могут использовать обычную API-квоту. Таймаут интерфейса — 35 секунд на проверку, не доказательство недоступности сервиса; уже отправленный запрос может завершиться позже. Повтор запускается только вручную. Из-за VPN результат разных сервисов может различаться.

При сбое откройте Console Output, выберите Error/Warn. Под ошибкой указаны вероятная категория и следующий шаг. «События операции» включает все уровни и фильтрует одну операцию; очистите поиск для возврата. «Скопировать сбой» копирует событие и до 80 предшествующих связанных событий из загруженной истории. Ошибка доступа к буферу показывается явно. Кнопка папки открывает полный текущий лог.

Обычный путь: `C:\Users\rosup\AppData\Roaming\@gold-work\desktop\logs\gold-work-studio-log.txt`. Portable использует свою workspace/logs. Рядом хранятся `-previous`, `-previous-2`, `-previous-3`: до четырёх файлов примерно по 5 MiB. При ротации самый старый архив заменяется; история не бесконечна. Чтение последних строк учитывает архивы. Старые файлы не перезаписываются задним числом новым санитайзером.

## Что искать разработчику

- `sessionId`, `buildId`: конкретный запуск и версия.
- `operationId`: запрос IPC/попытка задачи; `taskId`, `runId`, `projectId`, `sceneId`: связь с очередью. `attempt(s)`, `nextAttemptAt`, `retryBlockedReason` сохраняются отдельно.
- `ipc.request` → промежуточные события → `ipc.success`, `ipc.failed` или `ipc.result_failed`; время `elapsedMs`.
- `network.request/response/failed`: `requestId`, host, метод, HTTP status, маршрут proxy/system (system включает системный VPN; наличие VPN не детектируется).
- `anymodel.stream.failed`: исходная ошибка и число полученных символов, без текста сценария.
- `flow.step.failed`: этап, таймаут, фактическое время и ошибка. `renderer.unresponsive/responsive`, `renderer.process.gone`, `process.unhandled_rejection`: сбои процесса/окна.
- `error.cause`, `error.errors`, `code`, `errno`, `syscall`, `status`, stack: вложенные причины не теряются при записи и повторном чтении.

Классификация — подсказка, не доказательство источника проблемы. ECONNRESET не позволяет автоматически обвинить VPN или провайдера. Статус 200 фиксирует получение заголовков, а не успешное чтение всего потока. Неопределённая платная отправка не разрешает слепой повтор. Правила retry/сохранения remote job ID не изменены.

Скрываются ключи, cookies, Authorization, proxy userinfo, query/hash URL, prompt/narration/messages и бинарные тела. Не логируются тела HTTP-запросов/ответов. Имена проектов, технические пути и хосты могут оставаться — перед передачей полных логов сторонним людям просмотрите их. Общая маскировка не является гарантией удаления произвольного секрета из произвольного текста.
