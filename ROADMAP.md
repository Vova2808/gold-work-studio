# План улучшений Gold Work Studio

Собран из правок владельца, разбора трёх видео эталонного софта и постов о нём.
Делается партиями — по одной за раз, с проверками после каждой.

## Партия 1 — отзывчивость и прогресс ✅ (сделано)

- клик по теме мгновенно открывает проект; сценарий пишется в фоне, сцены появляются по мере готовности;
- живой прогресс анализа и сценария в подсказке сверху и в чате (что собрано, что делает Claude, транскрипт и цифры);
- починена белая полоса прогресса внизу (не вписывалась в тёмную тему).

## Партия 2 — озвучка: голоса и примеры ✅ (сделано)

- каталог голосов (edge-tts мужские/женские по языкам + google-tts) с выпадающим выбором в настройках проекта;
- кнопка «Послушать пример» у каждого голоса: короткий сэмпл генерируется через API один раз и кэшируется;
- выбранный голос сохраняется в проекте и используется конвейером.

## Партия 3 — длина и язык в проекте ✅ (сделано)

- пресеты длительности кнопками (30с / 1м / 5м / 10м / 30м / 60м) как у эталона;
- язык — выпадающий список (русский, английский, испанский, немецкий, французский, итальянский, португальский, украинский), без ручного ввода;
- кнопка «Пересобрать сценарий» — перегенерация сцен под новую длину/язык прямо из проекта.

## Партия 4 — качество картинок: стили и консистентность ✅ (сделано)

- каталог стилей изображений с превью-картинками (сгенерировать заранее дешёвым Gemini, положить в ассеты): кинематографичный, Pixar 3D, аниме, комикс, акварель, фотореализм, неон и т.д. Клик по стилю = его промпт-суффикс в проекте;
- консистентный герой: автопортрет главного персонажа по сценарию → в референсы проекта → все сцены генерятся gpt-image-2 с одинаковым героем (механика проверена живым тестом);
- единый стиль-суффикс добавляется к каждому промпту сцены.

## Партия 5 — таймлайн и свойства сцены (по видео «доп функционал»)

- правый клик по сцене → «Свойства сцены»: сцена участвует в сборке (вкл/выкл), длительность, скорость, обрезка;
- переход к следующей сцене: без перехода / затухание / растворение / сдвиги / круг + длительность перехода;
- направление и зум эффекта Ken Burns по сцене;
- правка текста озвучки и промптов прямо в свойствах + перегенерация только этой сцены;
- мультивыделение сцен: групповое применение настроек, отключение, удаление, перегенерация;
- перестановка сцен местами.

## Партия 6 — из видео и постов (позже)

- батч-запуск: несколько проектов в очередь разом;
- «?»-подсказки у каждой функции (навёл — прочитал);
- «режиссёр с памятью»: при придумывании тем учитывать прошлые проекты, чтобы канал не повторялся;
- AI-видео до конца: image-to-video (задел готов), сборка без перезаписи AI-клипов;
- голосовой ввод в чат.
