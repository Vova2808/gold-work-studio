# Архитектура

## Процессы

Electron main владеет файловой системой, базой данных, ключами и очередью. Renderer отвечает только за интерфейс и вызывает разрешённые методы через типизированный preload-мост. Node.js API не доступен веб-странице напрямую.

## Пакеты

- `apps/desktop` — жизненный цикл приложения, IPC и portable-сборка.
- `apps/renderer` — React-интерфейс.
- `packages/shared` — типы предметной области и контракты IPC.
- `packages/core` — очередь, сценарии использования и интерфейсы провайдеров.

## Данные

Рабочие файлы хранятся рядом с portable-приложением в каталоге `workspace/`, если он доступен для записи. В режиме разработки используется локальный каталог проекта. Перед коммерческим выпуском хранилище будет переведено на SQLite с миграциями; интерфейс репозитория уже отделён от UI.

## Интеграции

Каждая внешняя система реализует небольшой контракт: `DirectorProvider`, `ImageProvider`, `VideoProvider`, `SpeechProvider`. Mock-реализации применяются по умолчанию. Реальный адаптер можно подключить настройкой, не меняя проект, сцену или очередь.

## Portable-выпуск

`electron-builder` создаёт Windows portable executable и каталог с ресурсами. Установщик и системные изменения не используются.
