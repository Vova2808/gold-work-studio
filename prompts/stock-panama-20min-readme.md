# Сценарий для пользовательского прогона Stock Documentary

Вставляйте только содержимое `stock-panama-20min.txt` в режим готового сценария. Это русский документальный рассказ о Панамском канале без команд для генерации и без AI-вставок.

## Как запустить

1. Откройте Gold Work Studio через `D:\Софт Gold Work Sudio\START-GoldWork.cmd`. Если старая программа ещё открыта, сначала полностью закройте её.
2. Создайте новый ролик направления Stock Documentary, выберите готовый сценарий и вставьте текст файла. Старый незавершённый проект не используйте для этой проверки: его оплаченная озвучка и ручные настройки сохраняются.
3. Выберите русский голос и выполните предусмотренную программой калибровку. Для сравнения используйте 16:9, 1080p, обычный темп, автоматическую motion-графику и эффекты. Проверьте желаемую долю видео, например 85%, и запустите сборку. Дополнительное подключение Flow для этого сценария не требуется.
4. После завершения посмотрите Final целиком. Особенно полезны замечания с таймкодами: неверный материал, затянутая сцена, мелкая подпись, неуместная анимация, слишком тихий или громкий эффект. Если сборка остановится, сохраните сообщение и продолжайте с существующими результатами после разбора причины.

Текст содержит 15 323 символа и 2 078 слов. При сохранённой скорости 12,628 знака/с оценка планировщика — **20 мин 11 с**; выбранный русский голос может дать другую длительность. Точный текст проверен после разбиения на 261 производственный фрагмент. Это не 261 обязательно одинаковая склейка: графические композиции могут продолжаться на нескольких фрагментах. Озвучка этого сценария ассистентом не заказывалась.

Фактическое время новой сборки программа сохраняет в папке проекта: `Documentary/production-timing.txt`, подробности — в одноимённом JSON. В отчёте есть общее время и этапы, работающие параллельно. Их времена нельзя складывать. Цель **1–2 часа на двадцатиминутный фильм пока не подтверждена полным запуском**. Количество оплаченных запросов этот отчёт не считает.
