## Мелочи (бэклог)

- `stop()` не дожидается уже запущенных задач — отставшая задача может записать файл после остановки;
- `channelByRef` скрывает исходную причину ошибки YouTube API за общим сообщением;
- yt-dlp берёт первый попавшийся файл субтитров (английский автоперевод может вытеснить русский);
- «Студия», «Превью», «Аватарка», «SEO» — экраны-заглушки без реализации;
- при перегенерации сцены не чистятся старые файлы кадров в папке сцены.
