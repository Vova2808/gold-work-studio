## Сборка в Windows CMD — выполняет пользователь

Папка `E:\GoldWorkStudio` является корнем размещения, не Node-проектом. Команды выполнять по одной из настоящего каталога package.json:

```cmd
cd /d "E:\GoldWorkStudio\worktrees\documentary-selection-recovery"
pnpm install --frozen-lockfile --store-dir "E:\GoldWorkStudio\cache\pnpm-store"
pnpm build
```

Если cd, install или build завершается ошибкой, **остановиться на этой команде**, следующие не выполнять. Сохранить текст первой ошибки. Не создавать package.json в корне E: и не запускать старый EXE вместо несобранного кандидата.

После успешной сборки штатно закрыть старое окно Gold Work Studio, затем отдельно запустить:

```cmd
cd /d "E:\GoldWorkStudio\worktrees\documentary-selection-recovery"
START-GoldWork-E.cmd
```

Этот существующий сценарий запускает dist своей рабочей копии с профилем `E:\GoldWorkStudio\data\profile` и хранилищем из storage-location.json. Постоянный корневой START остаётся заморожен; для этой проверки использовать именно приведённую команду. При ошибке запуска остановиться и передать текст, не открывать параллельно старую сборку с тем же профилем.

## Ручное продолжение существующего проекта

1. Проверить путь/Build ID нового запуска. Открыть прежний проект, указанный в сообщении о сбое; не создавать его копию вместо продолжения. Сверить включённые сцены, сохранённый голос, принятые материалы и озвучку. Подробные проектные числа и таблица причин находятся только в локальной recovery-папке, указанной координатором.
2. Если сценарий/голос/материалы не менялись, один раз нажать **«Собрать ролик»**. Не очищать очередь и не включать принудительную замену всех сцен. У неизменённых готовых сцен не должно быть новых заказов озвучки и повторной проверки уже принятого файла. Неподтверждённые сохранённые кандидаты должны проходить только недостающие этапы.
3. При новой остановке раскрыть **«Причины последней остановки по сценам»** в обзоре производства. Все незавершённые сцены должны иметь причину и действие; числа должны сходиться. Для изменения материала открыть «Видео и фото». Не нажимать платный повтор Gemini для неизвестного запроса вслепую. Сохранённые старые сообщения предыдущей сборки не переписываются при простом открытии; новый полный список записывается при следующей остановке подбора.
4. При полном завершении проверить все включённые сцены Final, звук/длительность в начале, середине и конце, отсутствие пропущенных сцен и ложной готовности старого MP4. Сохранить проект, штатно закрыть и снова открыть: голос, ручные правки, материалы и путь результата должны сохраниться.
5. Передать Build ID, результат повторного использования готового, остаточные номера/причины либо факт полного Final и сохранности после открытия. До этого статус остаётся «Подготовлено к ручной проверке».
