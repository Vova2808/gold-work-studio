## Конкретные исправленные регрессии

- Три видеопробы перезаписывались при `section_number=NA`: имя теперь содержит `section_start`; повторный пилот получил разные фрагменты.
- Общий вид мотоцикла принимался вместо деталей двигателя: независимое описание видимого и проверка детали ужесточены. Отсутствие нужного ракурса в поиске это не решает.
- Пакетный ответ обрывался по `finish_reason:length`: бюджет ответа зависит от числа групп, пояснения сокращены. Старые partial не пересылаются автоматически.
- Перекрывающиеся резервные записи оставляли предпоследний snapshot: локальная проверка на копиях реальных проектов подтвердила сохранение последнего состояния.
- Новый контекст мог обойти pending старого формата полного пула кандидатов: guard восстановлен, адресная регрессия проходит.
- Рост всей панели увеличивал миниатюры: высоты дорожек отделены. В UI-проверке video=76 px сохранилось при увеличении панели 320→520 px.
- Старая JSX-ошибка в `App.tsx` блокировала Vite. Последующая текущая сборка/startup проходят; старый скрин не описывает нынешнюю сборку.

## Когда закрывать общие цели

- [ ] 5 подходящих фото и 5 подходящих **видео**, выбранных продуктом для распределённых по сценарию сцен, с просмотром результата.
- [ ] Живая проверка новой защиты эпохи без повторной отправки старых unknown.
- [ ] Сопоставимый замер времени/расхода на успешный материал каждого типа, без ухудшения смысла.
- [ ] 18-минутный Final за 2–3 часа с честным таймером от сценария и актуальным разрешением на полный платный прогон.
- [ ] Длительная сессия без OOM, отзывчивый большой таймлайн, сохранность файлов и голосов после ошибки/перезапуска.
- [ ] Приёмка всего фильма: кадры, звук, длительность, повторы, разнообразие и редакторские функции. Portable проверяется отдельно.
