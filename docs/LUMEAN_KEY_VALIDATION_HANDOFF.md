## Наблюдение и границы вывода

Пользователь сообщил, что ключ Lumean сначала по ошибке попал в AnyModel. Это разные поля и обработчики. После сохранения в Lumean появилась ошибка ByteString с кодом символа 1086 (кириллическая «о»). Журнал сборки `20261110T193610Z-dec09c9839` подтверждает сохранение в 20:08:08Z и четыре последовательных `network.failed` с ByteString, без HTTP-ответа в этой проверке. Содержимое ключа не читалось и не расшифровывалось.

По исходникам `X-API-KEY` получал сохранённое значение без проверки. Ошибка преобразования заголовка попадала в сетевую ветку и вызывала повторы. Это локальный дефект обработки ввода. Он не доказывает причину прежних HTTP 401 и не означает, что после исправления ввода сервис обязательно примет ключ.

Прочитаны [публичное описание API Lumean](https://api.lumean.app/docs/llm.md), разделы аутентификации/прав, типов заказов и лимитов, и [GET /ai/models/{key}](https://lumean.app/en/developers/docs/api/get-ai-models-key). Последняя страница описывает цены AI-модели; текущий сбой возникает до HTTP-ответа при передаче ключа озвучки. Base URL, X-API-KEY, выбор голоса через шаблон, создание асинхронного заказа и получение файла через storage/url в этом пакете не меняются. Новые запросы и возможности API не добавляются.

## Короткая ручная проверка

1. В кабинете Lumean скопировать само значение API-ключа без подписи/поясняющего текста. В программе открыть Настройки → AI и сценарии → Lumean, сохранить и дождаться подтверждения. В поле AnyModel должен быть только ключ AnyModel, если этот сервис нужен; программа сама ключи между сервисами не переносит.
2. Один раз нажать «Проверить». Ожидается успешное подключение при действующем ключе и необходимых правах. Ошибка непередаваемого значения должна сообщаться как ошибка настройки, без повторных сетевых попыток и без показа секрета.
3. Открыть список голосов/шаблонов, выбрать нужный вариант и сохранить проект. Штатно закрыть и открыть программу и проект; выбор должен сохраниться.
4. Необязательная проверка защиты сохранения: после успешного сохранения ключа ввести в поле только слово `пример`, нажать «Сохранить». Ожидается отказ без перезаписи старого ключа.
