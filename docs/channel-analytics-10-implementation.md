# Пакет №10. Обновление аналитики каналов

В `ChannelAnalyticsStore` второй вызов `refresh` получал Promise первого без учёта канала и режима. Поэтому запрос обновления B во время обновления A мог завершиться списком каналов, хотя B даже не проверялся. Аналогично ручной запрос мог получить результат автоматического с другим интервалом отбора каналов.

Ожидающие и текущие обновления теперь объединяются только при совпадении области и режима. Отсутствие `id` или пустой `id` означает все каналы. Отсутствие `automatic` эквивалентно ручному режиму. Разные запросы выполняются в порядке поступления. Перед началом очередного обновления хранилище читает актуальный список и время последней попытки для каждого канала. Так запрос по всем каналам, ожидавший обновления A, может обработать B и пропустить уже обновлённый A по действующему интервалу.

Интервалы в 15 минут для ручного обновления и 6 часов для автоматического сохранены. В одном обновлении запускается до трёх запросов за раз. Если попытку по каналу не удалось записать даже как ошибку, обновление дожидается завершения уже начатой группы запросов, возвращает ошибку и освобождает ключ. Следующие обновления продолжают выполняться. Запись остаётся в существующей очереди `mutate()`, которая заново читает общий файл перед изменением конкретной записи. Поэтому параллельное сохранение названия или группы учитывается, а удалённый во время запроса канал не восстанавливается.

## Ручная проверка

Если уже есть список из двух отслеживаемых каналов с настроенным YouTube, откройте «Аналитику каналов» в новой сборке. Если началось автоматическое обновление, дождитесь результата. Иначе, когда с последней попытки по обоим каналам прошло не менее 15 минут, нажмите «Обновить» один раз. У обоих каналов при успешном ответе YouTube появится актуальное время замера. При ошибке она видна у соответствующего канала, прежние замеры остаются. После повторного открытия страницы проверьте, что оба канала и их история на месте.

Страница вызывает обновление всего списка и блокирует одновременные действия в одном окне. Ручной сценарий проверяет общий путь обновления и сохранение данных. Два одновременных адресных вызова по A и B разобраны статически по `refresh`, IPC и очереди записи. Обычная проверка через интерфейс их не воспроизводит. Сборка, приложение, тесты и запросы YouTube при подготовке пакета не запускались.
