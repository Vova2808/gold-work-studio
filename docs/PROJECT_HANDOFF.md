## Назначение и приоритеты

Локальное Windows-приложение для автоматического создания роликов из сценария с последующим редактированием. Основной режим — Stock Documentary. Пользователь хочет качественный документальный монтаж в разных нишах, без ручного подбора со стороны разработчика. AI Story и существующие проекты необходимо сохранить.

Приоритеты пользователя:

1. Ускорить подбор подходящих фото/видео и сократить лишние запросы. Практическая цель — 18-минутный выпуск за 2–3 часа целиком, от сценария до Final.
2. Улучшить монтаж: разнообразные осмысленные вставки, motion, подписи, переходы и телевизионные эффекты по всему фильму; редактор по возможностям близко к Vidrush.
3. Стабильность и память: длительная работа без вылета, отзывчивый таймлайн, сохранность результатов при ошибках.

**Общие критерии нельзя закрывать только по сборке или короткому деморолику.** Последний тест 5+5 не прошёл приёмку качества; оценивать по нему время полного фильма нельзя.
