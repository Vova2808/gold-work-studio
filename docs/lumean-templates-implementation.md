# Восстановление списка шаблонов Lumean после E-M1

Ветка `codex/lumean-templates-20261110`, исходный коммит `a2449f217a656fd53c0ed742432b0ae28d7ed3ce`. Сборка E-M1 `20261109T204627Z-a2449f217a` предшествует исправлению. Runtime commit `44c26a7e3f6d5849015042eb8b454b23cdd9a2f1` просмотрен координатором и независимым агентом; блокирующих замечаний не выявлено. [Независимое статическое ревью](lumean-templates-independent-review.md). Кандидат E-M1-L1 — «Подготовлено к ручной проверке», пользователем не принят. Сборка и запуск Codex не выполнялись.

## Причина

- В E-M1 `VoicerClient.templates()` вызывает `GET /templates`. `requestOnce()` возвращает `parsed.data`, а старый загрузчик обрабатывает только массив. Документированный объект с `data.items` превращается в `[]` до фильтрации и сопоставления UUID. Lumean сообщает, что прежний массив убран 6 ноября 2026 года. Без `folder_id` этот endpoint отдаёт корневые шаблоны, а `service` и `type` вместе сужают результат. [Код E-M1](https://github.com/Vova2808/gold-work-studio/blob/a2449f217a656fd53c0ed742432b0ae28d7ed3ce/apps/desktop/src/voicer-client.ts#L218) · [Документация GET /templates](https://lumean.app/en/developers/docs/api/get-templates)
- Вызовы из `ProjectEditor`, «Профиля канала» и «Нового ролика» проходят через `listVoicerTemplates` → `voicer:templates` → `VoicerClient.templates()`. IPC передаёт массив целиком. `ProjectEditor` дополнительно переводил отклонённый запрос в пустой массив. Вариант `elevenlabs` во всех настройках проекта использует Lumean. [Preload](../apps/desktop/src/preload.ts#L78) · [IPC](../apps/desktop/src/main.ts#L629) · [Отображение результатов IPC](../apps/desktop/src/project-display.ts#L12)
- `voicer:test` вызывает `GET /user` и, по возможности, `GET /subscriptions`. `HTTP 200` и `ipc.success` от прежнего `voicer:templates` подтверждают завершение вызова, а журнал E-M1 не содержит тел или количества полученных шаблонов. Причина установлена по исходникам и документированному формату. [Проверка подключения](../apps/desktop/src/voicer-client.ts#L208)

## Исправление

- Единый `GET /templates/browse` получает `data.items` с элементами `type: folder` и `type: template`. Запрос проходит страницы с `page=1`, `per_page=100` до `last_page`. Для дочернего уровня передаётся документированный `folder_id`. Сначала собираются все страницы корня, затем папки по мере их обнаружения. Папки посещаются один раз, UUID шаблонов дедуплицируются. Сортировка `created_at desc` сохраняет приоритет новых корневых шаблонов. [Клиент](../apps/desktop/src/voicer-client.ts#L231) · [Документация GET /templates/browse](https://lumean.app/en/developers/docs/api/get-templates-browse)
- Обход выполняется без серверных фильтров, чтобы получить папки независимо от содержимого. На клиенте остаётся `elevenlabs` по `service_key`, с резервом `service.code` при отсутствии ключа. `service` может быть `null`. Для отображения используется имя, для выбора `template.id` передаётся как `VoicerTemplate.uuid`, для заказа это значение `template_id`. Пустой корректный результат остаётся `[]`. Неизвестная форма страницы или элемента вызывает явную ошибку. [Фильтр и сопоставление](../apps/desktop/src/voicer-client.ts#L263) · [Использование template_id](https://lumean.app/en/developers/docs/guide/templates)
- Событие `voicer.templates.page` содержит `/templates/browse`, тип `data` и два числа на страницу. `extractedCount` учитывает папки и шаблоны, `afterFilterCount` учитывает шаблоны ElevenLabs до дедупликации. Невычислимые количества равны `null`. Сообщения об HTTP-ошибках browse обходятся без текста ответа. [Диагностика](../apps/desktop/src/voicer-client.ts#L235) · [HTTP-ошибки](../apps/desktop/src/voicer-client.ts#L630)
- Общий загрузчик интерфейса показывает загрузку, результат с количеством, пустой результат или ошибку. При сбое остаётся последний успешный список. Завершение закрытого или заменённого запроса игнорируется. Список общий для проекта и зависит от подключения Lumean, а ответы не редактируют черновик проекта, голос или калибровку. [Загрузчик](../apps/renderer/src/useVoicerTemplates.ts#L4) · [Настройки проекта](../apps/renderer/src/App.tsx#L1811) · [Модалки канала](../apps/renderer/src/ChannelsPage.tsx#L299)
- В Stock Documentary, AI Story и прежнем редакторе выбирается UUID в `settings.voice.voice`. «Сохранить» отправляет изменённые `settings` через `projects:update`. В профиле канала «Сохранить канал» сохраняет `lumeanTemplateUuid` и имя выбранного шаблона. «Новый ролик» передаёт выбранный UUID в `settings.voice.voice` при создании. Кнопки обновления списка не запускают образец. [Сохранение проекта](../apps/renderer/src/App.tsx#L1829) · [Настройки Stock](../apps/renderer/src/StockWorkflowSettings.tsx#L57) · [Настройки AI Story](../apps/renderer/src/AiStorySettings.tsx#L68) · [Сохранение канала](../apps/renderer/src/ChannelsPage.tsx#L312) · [Создание ролика](../apps/renderer/src/App.tsx#L432)

## Ручной сценарий для пользователя

Сборка и запуск выполняются из каталога отдельного кандидата. Закройте прежний экземпляр приложения. После успешного завершения каждой команды выполните следующую:

```powershell
Set-Location -LiteralPath 'E:\GoldWorkStudio\worktrees\lumean-templates-fix'
pnpm install --frozen-lockfile --store-dir 'E:\GoldWorkStudio\cache\pnpm-store'
pnpm build
.\START-GoldWork-E.cmd
```

1. С включённым интернетом откройте тестовый Stock-проект. В «Настройки» → «2 Голос» выберите «Озвучить сценарий» и сервис «Lumean (ElevenLabs)». Нажмите «Обновить голоса» и откройте «Голос». Сверьте доступные шаблоны ElevenLabs с кабинетом Lumean, включая папку, если она есть. Выберите шаблон, нажмите «Сохранить», закройте и повторно откройте проект. В списке должен быть выбран сохранённый шаблон.
2. При наличии канала откройте «Каналы» → нужный канал → «Изменить профиль». Проверьте «Сохранённый голос Lumean» и «Обновить список голосов». В модалке «Новый ролик» проверьте группу «Lumean» в блоке «Голос и расчёт длительности» и кнопку «Обновить голоса». Для сверки списков достаточно открыть модалки и закрыть их после просмотра.
3. Если загрузка завершается ошибкой или список остаётся пустым, сохраните Build ID и обычный журнал после этого действия: события `voicer.templates.page` покажут тип данных и количества. Корректный результат без шаблонов ElevenLabs должен показывать «В Lumean нет шаблонов ElevenLabs», ошибка — отдельное сообщение. Для приёмки достаточно загрузки списка, выбора, сохранения и повторного открытия; платная озвучка и калибровка не требуются.

## Границы проверки

- Тесты, скрипты проверок, сборка, приложение, обращения к API Lumean, платные операции и генерация Codex не выполнялись. Действующий ответ провайдера и интерфейс в новой сборке должен подтвердить пользователь. Fixture [voice-calibration.test.ts](../apps/desktop/src/voice-calibration.test.ts#L277) по-прежнему ждёт URL, заканчивающийся `/templates`, и отдаёт прежний массив. По чтению кода он не обслуживает новый запрос browse. Тестовый файл сохранён.
- Внутренний выбор первого шаблона при отсутствии UUID теперь читает тот же полный каталог. При наличии корневого шаблона приоритет остаётся за ним. Если корневого шаблона нет, доступный шаблон может прийти из папки. Ошибка чтения любой страницы останавливает всю загрузку, поэтому ни частичный каталог, ни частичный результат выбора по умолчанию не выдаются за полный. Механизм создания и повторов `POST /orders` остался прежним. [Выбор для озвучки](../apps/desktop/src/voicer-client.ts#L303)
