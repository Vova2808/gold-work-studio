## Команды только для пользователя

Закройте прежний экземпляр приложения. В PowerShell:

```powershell
Set-Location -LiteralPath 'E:\GoldWorkStudio\source'
pnpm install --frozen-lockfile --store-dir 'E:\GoldWorkStudio\cache\pnpm-store'
pnpm build
# Для первого локального прохода после сборки временно отключите интернет.
.\START-GoldWork-E.cmd
```

Каждую следующую команду выполняйте после успешного завершения предыдущей. Зависимости и сборка не переносились из старой папки: их старые ссылки могли вести на D:. Сборку и запуск Codex не выполнял. До вашей сборки нового EXE/собранного приложения в source нет. E:\GoldWorkStudio-verified — прежняя сборка, она не содержит новые файлы переноса.

Первый ручной проход:

1. После установки зависимостей и сборки временно отключите интернет на первый ручной проход: экран настроек голоса может автоматически получать список голосов у провайдера. Откройте программу через START-GoldWork-E.cmd; убедитесь, что хранилище указывает E:\GoldWorkStudio\data\workspace, очередь пуста и в общем списке есть контрольный проект с 63 сценами.
2. Откройте настройки контрольного проекта. В разделе «Монтаж» смените «Формат видео» с 16:9 на 1:1 и сохраните; производство и повтор платных задач на этом этапе не запускайте. Этот параметр не удаляет сцены, принятые материалы и озвучку.
3. Закройте приложение и откройте снова через START-GoldWork-E.cmd. Проверьте сохранённый формат 1:1, затем верните 16:9 и сохраните. После локального прохода можно вернуть подключение к интернету.

Ожидаемый результат — новый профиль и контрольные данные открываются с E:, формат сохраняется после повторного открытия, исходный 16:9 восстановлен. Этот результат должен подтвердить пользователь; статическое ревью и сверка файлов не заменяют запуск. Переименование не включено: в текущих настройках Stock Documentary v2 поля названия нет.

Для замечания сообщите обозначение E-M1, действие и наблюдаемый результат. Пока вы проверяете E-M1, его source и profile не изменяются; последующие исправления готовятся отдельно.
