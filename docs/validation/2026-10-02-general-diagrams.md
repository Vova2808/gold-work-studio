# Общие схемы и повтор прежней выборки — 02.10.2026, 02:22 МСК

## Причины и изменения

Сцена 139 мотоциклетного проекта объясняет, как движение поршней и шатунов действует на коленвал. За две сцены до неё исходный сценарий буквально говорит «Inside every engine…». Старый план всё равно требовал изображение именно Yamaha YZR-M1. Точные запросы деталей дополнялись моделью, а схемы SVG из Commons адаптер не поддерживал.

Теперь короткое явно общее объяснение может использовать **проверенную поясняющую схему**, сохраняя исходные именованные требования для обычной съёмки. Исключение ограничено изображениями и требует дословную общую фразу из соседнего исходного текста, отсутствие возврата к человеку/имени/дате/принадлежности, подтверждение по пикселям схемы и нужной детали. Оно не разрешает выдавать схему за фотографию конкретной модели. Действующая независимая проверка видимых внутренних деталей также остаётся обязательной. Общие слова сами по себе не снимают именованные требования.

Commons теперь одним дополнительным запросом метаданных получает серверные PNG-визуализации найденных SVG шириной 1600. Авторство, лицензия и исходная страница сохраняются; размер SVG не выдаётся за размер PNG. Обычные растровые превью остаются маленькими. Неполученные/слишком маленькие визуализации не принимаются. Отказ сервера визуализаций не удаляет растровые результаты. SVG-код не исполняется. Для проверенного запроса новый кэш содержал четыре материала вместо двух: добавились две схемы.

При просмотре обнаружена прозрачность схемы с чёрными линиями: добавлена белая подложка для этих SVG-производных, без изменения исходника и обычных PNG-вырезок. Один и тот же подготовленный файл используется для проверки и монтажа. Кадры белой версии имеют отдельный кэш; старые неизвестные проверки исходных кадров по-прежнему блокируют повторную оплату.

## Проверки и следующая конкретная ошибка

20 адресных проверок совокупно прошли: схема/исходный контекст/старые неизвестные запросы, ранжирование, запросы деталей, Commons и лицензии, реальный FFmpeg (белый фон, чёрные линии, неизменность оригинала и повторное использование файлов). Это локальные проверки, отдельно от приведённых живых опытов. Desktop typecheck прошёл. Сборка **`20261001T232226Z-58cbc368e7-dirty`** и изолированный startup exit0, main/renderer совпали. GPU-предупреждение после выхода остаётся.

**Следующий дефект: старые автоматические одобрения обходят новую проверку контекста.** В `diagram-context-ten/result.json` сцена 227 (`wasVerified:true`, 0 POST) оставлена готовой со старым текстом про «Monster Energy…2004-era», хотя это фото уже признано неверным в предыдущем визуальном разборе. Новые ограничения эпохи применяются к новым проверкам, но у сохранённого `visualReview` нет доказательства версии/контекста, с которыми оно принято. `documentarySavedIdentityIssue` проверяет только явные противоречия, а `autoSelect` пропускает уже подтверждённое.

Далее нужно сохранять проверяемое основание новой контекстной приёмки и переводить устаревшее **автоматическое** одобрение в состояние повторной проверки. Не удалять источник/голос, не менять ручные подтверждения, не повторять pending/partial/неизвестные платные ответы. Сначала адресная проверка этой миграции и локальная проверка старого проекта. Новый полный платный проект не разрешён; следующий малый платный тест имеет смысл только после конкретного исправления.

Открыты: качественные 5+5, достоверная приёмка эпохи всех использованных кадров, цена/время на подходящий материал, выигрыш полного видео-подбора, 18-минутный Final за 2–3 часа, длительная устойчивость.
