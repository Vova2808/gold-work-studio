## Что изменено

- Штатный подбор сначала получает первую точную выдачу (Commons для фото, YouTube для видео), затем проверяет кандидатов. Архивы, дополнительные запросы и общий пул запускаются только при необходимости. Убран заблаговременный общий поиск следующей сцены, занимавший очередь провайдеров. Это ограничение запуска следующих поисков, а не жёсткое прерывание уже отправленного запроса. Неизвестные платные запросы не повторяются.

CLIP ранжировал снимок гонки 2014 года до проверки метаданных. Теперь при датах в оригинальном контексте сохраняется семантический отбор метаданных; год не угадывается по ближайшей дате, что важно для сравнения 2004/1992.
