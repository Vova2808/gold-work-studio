## Остаточные ограничения

- Статический разбор не доказывает компилируемость, разрешимость реальных файлов, работу провайдеров, качество кадров/звука, производительность или полный результат.
- Публикация файла и запись реестра проекта остаются разными операциями. Защита актуальности замечает гонки, но не создаёт общей файловой транзакции.
- У старых сцен / очередей без input hash нет ретроспективного доказательства исходного текста и голоса. Legacy completed export использует осторожный guard по времени; это не эквивалент нового hash.
- При изменении исходного текста общей дорожки действует консервативная проверка всего состава/порядка/текста. Само наличие MP3 не доказывает его соответствие новой реплике.
- Наличие/размер файла проверяются в определённых точках, а не непрерывно; внешнюю подмену/удаление после проверки статический guard не исключает.
- После устранения замечаний необходима ручная пользовательская приёмка: продолжение сохранённого Stock, пауза/перезапуск, явная замена одной реплики, сохранность остальных MP3/материалов, полный Final для всех включённых сцен и повторное открытие результата.
