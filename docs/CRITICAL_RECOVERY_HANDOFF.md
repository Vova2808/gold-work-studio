## Ближайшая ручная проверка

1. После запуска сверить Build ID и профиль E:. Открыть прежний проект. Обновить голоса Lumean, выбрать нужный шаблон (в том числе из папки, если он там), сохранить, закрыть и снова открыть. Список доступен, выбор сохранён; для этого не требуется новая озвучка или калибровка.
2. Изменить небольшой фрагмент сценария и ручной параметр монтажа. Закрыть обычным крестиком и открыть снова. Правки сохранены; при ошибке сохранения окно остаётся открытым, черновик доступен. При конфликте версии сначала сверить сохранённые данные и оставшийся черновик, не повторять сохранение вслепую.
3. Создать копию проекта с ручной графикой/шаблоном. В копии сохраняются текст, голос и ручное оформление, но нет старого готового ролика/проверенных материалов. Оригинал остаётся с прежними файлами. Копия — новый производственный черновик, а не способ продолжить старый оплаченный заказ.
4. Для существующей начатой работы: пауза не запускает дополнительные задачи сверх лимита; остановка дожидается сохранения отправки/ответа. Если ID уже известен, «Продолжить заказ» использует исходный заказ. При неизвестном результате отправки не очищать данные и не создавать новый заказ вслепую. Не нужно оплачивать отдельную генерацию только ради этой проверки.
5. Пакеты 08/09: продолжать имеющийся контрольный проект штатной кнопкой «Продолжить подбор и сборку»/«Собрать» по его текущему состоянию. Сохранённые озвучка и принятые материалы должны использоваться снова. Если подбор требует ручного решения, сначала разрешить отмеченные сцены; такой остановленный подбор не считается готовым роликом. Затем проверить все включённые сцены, длительность, звук, ручное оформление и существующий Final.mp4, закрыть/открыть проект. Короткий фрагмент и успешная сборка приложения не заменяют эту приёмку.
